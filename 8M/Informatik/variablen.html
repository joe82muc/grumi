Variablen und Dateneingabe

„Antwort“ vergisst alles, sobald die nächste Frage kommt. Eine Variable nicht: Sie ist ein Speicherplatz mit einem Namen. Was du hineinlegst, bleibt dort – bis du etwas Neues hineinlegst.

Ein Speicherplatz mit Namen

Eine kannst du dir wie ein beschriftetes Fach vorstellen: Außen steht der Name, innen liegt der Wert. Sieh zu, was beim Programm aus Station 1 in den Fächern passiert:

Antwort
name0
alter0

MERKE

  • Eine Variable ist ein Speicherplatz mit einem Namen. Sie enthält immer genau einen Wert.
  • „setze name auf …“ legt einen neuen Wert hinein. Der alte Wert ist danach weg.
  • Der runde Block mit dem Namen der Variablen liefert ihren Wert – du steckst ihn in andere Blöcke.
  • „ändere punkte um 1“ rechnet zum alten Wert etwas dazu. So zählt ein Programm mit.
  • Eine Variable behält ihren Wert – auch beim nächsten Start. Darum steht bei einem Zähler ganz oben „setze punkte auf 0“.

Drei Fachwörter: Der Name einer Variablen heißt . „setze … auf …“ ist eine . Zahl und Text sind zwei – rechnen kann das Programm nur mit Zahlen.

Eine Variable legst du im orangen Bereich Variablen an: Knopf Neue Variable anklicken, Namen eintippen, auf OK klicken. Wähle einen Namen, der sagt, was drin ist: alter ist besser als x.
