# Screenshots für Informatik 7

Hier liegen die Screenshots, die in den Stunden angezeigt werden.

## Wie füge ich einen Screenshot hinzu?

1. Screenshot am **Schulrechner** aufnehmen (Windows-Taste + Umschalt + S),
   damit die Schüler genau die Oberfläche sehen, die sie vor sich haben.
2. Als PNG hier ablegen, Dateiname genau wie in der JSON-Datei eingetragen.
3. Fertig — die Seite zeigt das Bild beim nächsten Laden an.

Solange eine Datei fehlt, erscheint auf der Stundenseite ein ruhiger
Platzhalter mit dem Hinweis "Bild folgt". Die Seite bleibt also nutzbar.

## Bildrechte

Eigene Screenshots von Schulrechnern sind unproblematisch. Achte darauf,
dass **keine Schülernamen, Benutzernamen oder Dateinamen von Schülern**
im Bild zu sehen sind.
