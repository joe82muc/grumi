# Texte der Proben

Hier liegen absichtlich keine Dateien. Die Lesetexte, Aufgaben und Erwartungshorizonte der acht Deutsch-Proben stehen
nur auf dem Server (Repo `englisch_9`, `backend/api/d7-proben/p1.js` bis `p8.js`), damit sie nicht über die Website
abrufbar sind, bevor eine Probe freigeschaltet ist. Das Kind bekommt den Text erst beim Start der Probe – fertig
umbrochen und mit Zeilennummern.

Alle Proben-Texte sind eigenständig für GRUMI erstellt. Kein Text einer Probe kommt in einem Lernmodul vor.
