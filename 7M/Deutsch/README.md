# Deutsch 7M: Argumentationstrainer

Der Bereich führt in vier Stufen vom einzelnen Argument zur freien Argumentation:

1. Behauptung, Begründung und Beispiel
2. Pro, Kontra und Abwägung
3. Argument-Duell mit einem KI-Gegenargument
4. Freie Argumentation mit markierten Textstellen

Ab zwei von drei Sternen wird die nächste Stufe freigeschaltet. Die KI gibt Hinweise, formuliert den Schülertext aber nicht um. Die Lehreransicht ist über `lehrer.html` erreichbar.

Die produktive API liegt unter `https://englisch-9.onrender.com/api/de7-argument`. Personenbezogene Daten und Lösungen werden nicht im GitHub-Repository gespeichert.
