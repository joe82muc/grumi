3) Redemittel (all from the worksheet)

1. Einstieg

  • This picture shows ...
  • In this picture I can see ...
  • This photo was taken ...
  • The scene takes place ...
  • It looks like ...

2. Personen beschreiben

  • There is / There are ...
  • I can see a man / a woman / a group of ...
  • The people are ...
  • They are wearing ...
  • One person is ...ing
  • They seem to be ...

3. Ort / Position

  • In the foreground, there is ...
  • In the background, I can see ...
  • In the middle, there is ...
  • On the left / On the right, there is ...
  • Next to ... / Behind ... / In front of ...

4. Handlung

  • They are ...ing
  • Someone is ...
  • The people are doing ...
  • It looks like they are ...
  • Maybe they are ...

5. Vermutungen

  • I think that ...
  • Maybe ...
  • It could be that ...
  • They might be ...
  • It seems that ...

6. Stimmung / 7. Meinung

  • The atmosphere is ...
  • The people look happy / excited / tired / sad / nervous.
  • It looks like a nice / stressful / busy situation.
  • The mood is ...
  • I think this is ...
  • In my opinion ...
  • I like / don't like this picture because ...
  • I would like to be there because ...
