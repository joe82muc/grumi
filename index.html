Für Lehrkräfte

Proben freischalten – die KI wertet aus

Vokabeltests, Grammatikproben und Fachproben laufen direkt auf dem Tablet. Die Lehrkraft behält jederzeit die Kontrolle: Sie schaltet frei, sieht jede Antwort und vergibt die endgültige Note.

  1. Freischalten

    Alle Proben aller Klassen auf einer Seite – ein Klick auf „Freischalten“, nach der Stunde „Alle sperren“.

  2. Schreiben

    Die Klasse schreibt auf dem Tablet. Jeder Name kann nur einmal abgeben – auch Neuladen hilft nicht.

  3. KI wertet aus

    Eindeutige Antworten prüft der Server genau, freie Antworten und Sätze bewertet die KI – fair und mit kurzer Begründung.

  4. Kontrollieren

    Jede Punktzahl lässt sich ändern, die Note rechnet sich neu. Ergebnisse gehen als Excel-Datei (CSV) auf den eigenen Rechner.

Zur Freischalte-Seite

Das Lehrkraft-Passwort gibt es persönlich bei Herrn Mößner – es steht bewusst nicht auf dieser öffentlichen Seite.

Technik und Verantwortung

Moderne KI – mit Datenschutz und Urheberrecht im Blick

Datenschutz mitgedacht

Übungen brauchen keine Anmeldung. Der Übungsstand bleibt im Browser. Probenabgaben liegen nur auf dem geschützten Server und nie im öffentlichen Quellcode.

KI im Hintergrund

Die Auswertung übernimmt Claude von Anthropic über einen eigenen Server. Die KI bekommt nur Aufgabe und Antwort – keine Namen und keine Klassen.

Eigene Bilder statt fremder Fotos

Neue Illustrationen entstehen als eigene Fotos oder KI-generierte Bilder. So lassen sich Urheberrechtsprobleme mit fremden Bildern vermeiden.

Frei verfügbar über GitHub

Die Seiten liegen kostenlos auf GitHub Pages – ohne Werbung, ohne Abo, für jede Schule nachnutzbar.

Entwickelt mit Codex und Claude

Programmiert in Visual Studio Code mit Codex und Claude Opus als KI-Assistenten. Neue Module entstehen dadurch in Tagen statt Wochen.

Beliebig ausbaubar

Jedes Fach, jede Unit und jede Probe folgt demselben Baukasten. Neue Klassen und Fächer lassen sich schnell ergänzen.

Häufige Fragen

Kurz beantwortet

Ist GRUMI kostenlos?

Ja. Alle Übungen sind frei erreichbar und ohne Anmeldung nutzbar.

Wie laufen die Proben ab?

Die Lehrkraft schaltet frei, die Klasse schreibt auf dem Tablet, die KI wertet aus. Die Note vergibt am Ende immer die Lehrkraft.

Was passiert mit den Daten?

Die KI sieht keine Namen. Probenergebnisse liegen nur auf dem Server und werden von der Lehrkraft als Datei gesichert.

Kann man mitmachen?

Ja. GRUMI ist offen angelegt. Hinweise, neue Aufgaben und eigene Module sind willkommen – gerne auch über die SchiLF.
