Die 5 Einheiten

Jede Einheit ist ein Nachmittag. Am Ende hast du ein eigenes Projekt online.

1

Die Werkzeugkiste

Konten anlegen (GitHub, Google), VS Code und Git installieren, Codex und Claude Code starten – deine erste Seite entsteht.

2

Mit KI programmieren

Du beschreibst eine Übung für dein Fach, die KI baut sie. Prüfen, verbessern, nachfragen – so arbeitet man mit Codex und Claude Code.

3

Online stellen

Mit GitHub und GitHub Pages geht deine Seite ins Netz – mit QR-Code für die Klasse.

4

KI-Rückmeldung für die Kinder

Ein eigener Server bei Render und ein Schlüssel von Anthropic: Die KI gibt Rückmeldung auf Antworten. Kosten und Datenschutz im Blick.

5

Dein Projekt

Du machst ein Modul für deinen Unterricht fertig und stellst es den anderen vor.

📅 Termine nach Absprache – kreuz in der Umfrage an, welche Nachmittage dir passen.
